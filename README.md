## How to run the application
Initialize the project: npm init -y
Install dependencies (Express framework and UUID library): npm install express uuid
start the server: node server.js
API is running at http://localhost:3000
test and send request

## Reflection
I built an API from scratch using Node.js. I learned how to set up a server using Express framework 
and use the UUID library to generate unique ID for each todo item.
I learned how to implement CRUD operations, including POST,GET, PUT, DELETE.
I also learned HTTP status codes: 201 for creation, 400 for bad requests, 404 for missing items.
I learned how to test my endpoints using REST Client.
